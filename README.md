# CS64-1
学术论文图像评分
建立能够基于科学论文图像进行质量评估的基准方法并且用多模态模型对这种建立的评估方法进行学习以及自动化评估的功能。在这个项目中衡量科学论文图像质量是通过图像文字匹配度，图像结构，信息量，清晰度这四个指标维度来进行评估的。以下是具体实现步骤。
1：首先我们先对一些期刊会议上的文章进行基本爬取比如ICLR, NeurIPS, ICML，大概一共有几千篇。
2：紧接着我们对里面爬取的每一篇文章再进行更细节的提取比如图像，摘要，相关正文，图像标题。
3：针对每一种指标都制定了一种评判图像质量的方法。
4：根据此方法对一部分论文进行人工标注质量分数。
5：使用GPT-4o对标注的情况进行学习，再进行剩余图像的自动化标注。
6: 使用基线模型对完整数据集进行学习并测试性能。
7：使用自己搭建的模型对完整数据集进行学习并测试性能。
8：对比自己的模型和基线模型性能，最终证明我们自己设计的模型性能优于基线模型。
